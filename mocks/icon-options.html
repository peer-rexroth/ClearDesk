Workbench – app icon options

Built on Apple's app-icon guidance: one simple idea, a few filled overlapping shapes with transparency, a plain gradient background, no thin lines, no text (a single mnemonic letter is the exception), no copy of the app's own UI, and artwork centred on a square so the system can mask and light it. Each option is shown as the system would mask it (rounded square), in a dark appearance with the same features, and at small sizes. The shadow around each is only for the preview.

Three stacked, translucent surfaces: the three modes (Tasks, Notes, Prompts) as one workspace. Filled overlapping shapes with transparency, exactly the construction Apple describes; no thin lines, no text, easy to read at 16 px.
