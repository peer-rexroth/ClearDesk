How mytasks works

Overview
mytasks is a local task manager — projects, priorities, due dates, tags and recurring tasks, with subtasks nested three levels deep. Everything runs in your browser — no account, no server.
Creating & editing tasks
Type into Add a task… at the top and press Enter. New tasks go to whichever project you're currently filtered to, or Inbox otherwise. Shorthand sets fields as you type: !high !low for priority, #project, @tag, and a date word such as today, tomorrow, fri, next week or in 3 days. A preview shows what will be set; Shift+Enter adds the text exactly as typed.
Click a task to open the drawer — the full editor for project, priority, due date, notes, tags and repeat settings.
Double-click a task's title (in list, board, or the drawer) to rename it in place.
Subtasks, steps & sub-steps
Nesting goes three levels deep: task → subtask → step → sub-step. Add any of them from the hover-revealed inputs in list view, or the drawer's permanent add fields.
Drag subtasks/steps to reorder them, including moving a step between subtasks — sub-steps drag-reorder within their own step. Use the hierarchy buttons (or Tab/Shift+Tab while adding) to promote/demote between adjacent levels.
Recurring tasks
Set a repeat interval (daily/weekly/monthly/yearly) in the drawer, optionally with an end date or a maximum number of occurrences. Completing or skipping a recurring task automatically advances it to the next due date instead of marking it done for good.
Projects, tags & filtering
Manage projects from the sidebar's button. Deleting a project moves its active tasks to Inbox for triage; completed tasks stay done, out of Inbox's view.
Filter by status, priority, or tags from the toolbar, or use the sidebar's My Day, This Week, and Overdue smart views.
List vs. board view
Board view groups cards by project (not status) — drag a card to a different column to reassign its project. List view has full subtask/step/sub-step editing; board view is intentionally lighter (steps and sub-steps are read/toggle-only there).

Data & sync
Your data is stored locally in this browser (localStorage). It persists between sessions on this device but isn't synced anywhere by default.
Link file (Chrome/Edge) auto-saves every change to a real .json file on your disk, so your data survives even if browser storage is cleared.
Export downloads a one-off backup. Import loads a backup back in, merging or replacing your current data.
Nothing here ever leaves your machine — there's no server, no account, and no admin rights required to run this app. Automatic daily snapshots (last 7 days) are also available under Data → Backups.
